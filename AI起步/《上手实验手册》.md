## 路径 A：对话台（最快上手）

### 第 1 步：打开终端

Mac 的「启动台」→ 搜"终端"（Terminal）→ 点开。窗口里是一行光标在闪。

### 第 2 步：复制这一行，粘贴，回车

```bash
~/llm-lab/venv-m4/bin/python AI起步/对话台.py
```

看到这样的画面就对了：

```
============================================================
 交互式对话台 · 自己敲着玩
============================================================
 本机可用模型：qwen3.5-9b-v4flash:flash, qwen3-8b-v4flash:flash, ...
 当前模型：qwen2.5:3b-instruct   温度：0.7
 输入 /帮助 看命令，输入 /退出 离开
```

### 第 3 步：自己敲问题

看到 `你>` 这个提示符，说明可以输入了。**直接打字，回车**：

```
你> 中国的首都是哪里？只回答城市名。
AI> 北京
```

### 第 4 步：亲手验证"温度"的影响

```
你> /温度 1.5
  温度已设为 1.5
你> 中国的首都是哪里？只回答城市名。
AI> 北京
```

### 第 5 步：亲手验证"换模型"的影响

```
你> /模型 qwen3-8b-v4flash:flash
  已切换到：qwen3-8b-v4flash:flash
你> 中国的首都是哪里？只回答城市名。
AI> 北京
```

### 第 6 步：最精彩的——让模型们一起回答你的问题

**问题随便你定**，不是只能用示例里那个：

```
你> /对比 帮我写一句潮汕牛肉火锅的广告语
你> /对比 用一句话解释什么是通货膨胀
你> /对比 我该学 Python 还是 Go
```

**只对比其中几个模型**（把模型名跟在问题后面）：

```
你> /对比 什么是AI qwen2.5:3b-instruct qwen3-8b-v4flash:flash
```

**刚问完就对比**（不带参数，会用你最近问过的问题）：

```
你> 我想学做潮汕卤水，需要准备什么材料？
你> /对比
  用你最近问过的问题：我想学做潮汕卤水，需要准备什么材料？
```

**图形界面版**：点「五模型对比」会弹出一个窗口，上面输入框显示的是**灰色提示**（不是真问题），
你可以直接 ⌘V 粘贴自己的问题，或点「📋 粘贴剪贴板里的问题」；灰字在你打字/粘贴时自动消失。
下面是模型勾选框（可只勾 2 个），还能单独给这次对比调温度。
只有你**什么都不填**直接点开始，才会对比最近问过的问题。

你会看到五个模型分别回答：

```
【qwen3.5-9b-v4flash:flash】
  通货膨胀是指由于货币供应量过多，导致单位货币购买力下降、整体物价水平持续普遍上涨的经济现象。

【qwen2.5:0.5b】
  通货膨胀是指一种货币贬值或价格飞升的情况，导致购买力下降，消费者购买力增加。
  ↑ 注意这里！"购买力下降"和"购买力增加"自相矛盾——小模型会犯错
```

**这就是你要的验证**：同一个问题，不同模型答案不同，质量也不同。名字里数字大的（9B、8B）明显更准确。

### 对话台全部命令

| 命令 | 作用 |
|---|---|
| `/帮助` | 看所有命令 |
| `/模型 <名字>` | 换模型 |
| `/温度 <0~2>` | 调温度 |
| `/长度 <数字>` | 限制回答长度 |
| `/对比 <问题> [模型...]` | 模型回答同一问题比一比；问题随便你定，不带参数则用最近问过的问题 |
| `/历史` | 看聊天记录 |
| `/清空` | 清空记录（模型会忘掉之前说的） |
| `/退出` | 离开 |

### 关于"多轮对话"

对话台会记住你说过的话。试这个：

```
你> 我叫刘永华
AI > 好的，刘永华！有什么可以帮您的吗？

你> 我叫什么名字？
AI > 您叫刘永华。
```

注意：每问一句，前面所有内容都会重新发一遍给模型——这就是"上下文"。用 `/清空` 可以让它忘掉。

## 路径 B：终端 curl 命令（看清背后）

这条路径让你看到"请求-响应"的完整过程。

### 最小可用版本（直接粘贴回车）

```bash
curl -s http://127.0.0.1:11434/api/chat -d '{
"model":"qwen2.5:3b-instruct",
"messages":[{"role":"user","content":"中国的首都是哪里？只回答城市名。"}],
"stream":false,"think":false
}'
```

会输出一大坨 JSON，里面 `message.content` 字段就是答案：

```json
{"model":"qwen2.5:3b-instruct","created_at":"...","message":{"role":"assistant","content":"北京"},"done":true}
```

### 拆开看每一步

**第 1 步：先确认模型在不在**

```bash
curl -s http://127.0.0.1:11434/api/tags | python3 -c "import json,sys; [print(m['name']) for m in json.load(sys.stdin)['models']]"
```

输出你的 5 个模型名字。

**第 2 步：只把答案打印出来（加个管道过滤）**

```bash
curl -s http://127.0.0.1:11434/api/chat -d '{
"model":"qwen2.5:3b-instruct",
"messages":[{"role":"user","content":"中国的首都是哪里？只回答城市名。"}],
"stream":false,"think":false
}' | python3 -c "import json,sys; print(json.load(sys.stdin)['message']['content'])"
```

现在只输出 `北京` 了。

**第 3 步：改问题，改温度，改模型**

把这几处改掉再跑：
- `"content":"..."` 里换成你自己的问题
- `"model":"qwen3-8b-v4flash:flash"` 换成别的模型
- 加 `"options":{"temperature":1.5,"num_predict":200}` 调温度和长度

**第 4 步：看逐字输出（像 ChatGPT 那样）**

```bash
curl -sN http://127.0.0.1:11434/api/chat -d '{
"model":"qwen2.5:3b-instruct",
"messages":[{"role":"user","content":"写一首关于海的两行诗"}],
"stream":true,"think":false
}'
```

`-N` 是关掉缓冲，所以你会看到字一个一个冒出来。

### 顺便理解一下这个 JSON

```json
{
  "model": "qwen2.5:3b-instruct",   ← 用哪个模型
  "messages": [                        ← 对话内容，可以有多轮
    {"role": "user", "content": "..."}  ← role: user=你, assistant=AI
  ],
  "stream": false,                     ← true=逐字输出, false=一次性返回
  "think": false,                      ← 关掉思考过程（有些模型会先"想"再答）
  "options": {                         ← 可选参数
    "temperature": 0.7,                ← 发挥空间 0~2
    "num_predict": 500                 ← 最多生成多少 token
  }
}
```

**看懂这个 JSON，你就掌握了调用任何大模型 API 的核心**——不管哪家厂商（OpenAI、通义、智谱、本地模型），套路都是这个：给模型名、给消息列表、调几个参数。

## 路径 C：Python 交互模式（自己写代码）

如果 A 和 B 都想通了，试这个——它让你完全掌控。

### 第 1 步：启动交互模式

```bash
~/llm-lab/venv-m4/bin/python -i
```

看到 `>>>` 提示符。

### 第 2 步：定义一个"问"函数（逐行敲，回车）

```python
import json, urllib.request
def 问(问题, 模型="qwen2.5:3b-instruct", 温度=0.7):
    d = {"model": 模型, "messages":[{"role":"user","content":问题}], "stream":False, "think":False,
         "options":{"temperature":温度,"num_predict":300}}
    r = urllib.request.Request("http://127.0.0.1:11434/api/chat",
        data=json.dumps(d).encode(), headers={"Content-Type":"application/json"})
    return json.loads(urllib.request.urlopen(r, timeout=120).read())["message"]["content"]
```

### 第 3 步：调用它

```python
问("中国的首都是哪里？只回答城市名。")
```

输出：`'北京'`

### 第 4 步：开始做对照实验

```python
问("用一句话解释什么是通货膨胀", 温度=0.1)
问("用一句话解释什么是通货膨胀", 温度=1.8)
问("用一句话解释什么是通货膨胀", 模型="qwen3-8b-v4flash:flash")
```

### 第 5 步：写进文件试试

```python
open("我的第一个ai程序.py","w").write('''
import json, urllib.request
def 问(问题, 模型="qwen2.5:3b-instruct"):
    d = {"model":模型,"messages":[{"role":"user","content":问题}],"stream":False,"think":False}
    r = urllib.request.Request("http://127.0.0.1:11434/api/chat",
        data=json.dumps(d).encode(), headers={"Content-Type":"application/json"})
    return json.loads(urllib.request.urlopen(r,timeout=120).read())["message"]["content"]
print(问("你好"))
''')
```

然后：

```python
exec(open("我的第一个ai程序.py").read())
```

**退出交互模式**：输入 `exit()` 回车。

## 三个案例，在三条路径上分别验证

### 案例 1：模型是"接话"的（第 1 课）

**路径 B 验证**：

```bash
curl -s http://127.0.0.1:11434/api/chat -d '{
"model":"qwen2.5:3b-instruct",
"messages":[{"role":"user","content":"中国的首都是"}],
"stream":false,"think":false
}' | python3 -c "import json,sys; print(json.load(sys.stdin)['message']['content'])"
```

你会发现模型**接着往下写**，而不是只回答"北京"。这就是"接话"的本质。

### 案例 2：温度影响发挥空间（第 4 课）

**路径 C 验证**（最直观）：

```python
for t in [0.1, 0.7, 1.5]:
    print(f"温度 {t}:", 问("给奶茶店起个名字，要有故事感", 温度=t))
```

同一个问题，三种温度，三种不同的风格和长度。

### 案例 3：模型越大越准（第 6 课）

**路径 A 验证**（一条命令）：

```
你> /对比 用一句话解释什么是通货膨胀
```

注意看 0.5B 那个模型的回答有没有逻辑矛盾。

## 出错了怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| `Connection refused` | Ollama 没运行 | 另开终端跑 `ollama serve` |
| `command not found` | 路径打错了 | 用 Tab 键自动补全路径 |
| 对话台打不开 | python 路径不对 | 用完整路径 `~/llm-lab/venv-m4/bin/python` |
| `model not found` | 模型名拼错 | 先跑 `curl -s http://127.0.0.1:11434/api/tags` 看准确名字 |
| 回答特别慢 | 模型太大 | 用 `/模型 qwen2.5:3b-instruct` 换小的 |
| 中文乱码 | 终端编码 | 不用管，内容是正常的 |
