- 听人说"AI 门槛很高"，想知道自己够不够格学

## 怎么开始（三个选择，从难到易）

### 方式一：直接问我（最省事，零门槛）

**你现在用的这个 WorkBuddy 对话框就是入口。**

直接在这里打字问我，比如：

- "用本机大模型回答：中国的首都是哪里？"
- "对比一下本机 5 个模型回答'什么是通货膨胀'，哪个最好？"
- "跑一下微调实验，看看 loss 怎么降"

我会调用你本机的模型，把真实输出贴给你。**不用碰终端、不用敲命令。**

### 方式二：双击图形界面（不用终端）

在访达（Finder）里打开本仓库的 `AI起步/` 文件夹（路径见上方仓库目录）。

**双击 `AI对话台.app`** —— 会弹出一个窗口，里面有输入框、模型下拉框、温度滑块。

- 输入框打字提问，回车发送；**从别处复制的文字可以直接 ⌘V 粘贴**，灰字提示会自动消失
- 复制了一整段看不懂的文字？点「🔍 解释剪贴板内容」，AI 会用大白话解释它
- 想存下回答？点「📄 复制全部对话」，或者在对话记录上右键复制
- 右上角换模型
- 拖滑块调"发挥空间"（温度）
- 点「五模型对比」按钮，让几个模型回答同一问题

**这个窗口也能用命令，跟终端版一样，但完全不用开终端。**

| 命令 | 作用 |
|---|---|
| `/帮助` | 在窗口里列出所有命令 |
| `/模型 qwen2.5:0.5b` | 换模型；不加名字就列出可用的 |
| `/温度 1.2` | 调「发挥空间」，0~2 |
| `/长度 300` | 限制回答长度 |
| `/对比 你的问题` | 几个模型回答同一问题，后面也可加模型名 |
| `/历史` | 看最近的聊天 |
| `/清空` | 清空聊天记录 |
| `/退出` | 关掉窗口 |

命令以 `/` 开头，全部在本机执行，不会发给 AI。输入 `/乱码` 也只会得到一条提示。

## 想立刻自己动手？三条上手路径

课程是"讲解"，但大模型这门学问必须**亲手敲**才记得住。菜单里有两个入口：

| 入口 | 做什么 | 适合 |
|---|---|---|
| **对话台** | 像聊天一样一行行敲，还能 `/模型` 换模型、`/温度` 调参数、`/对比` 让模型回答同一问题 | 想先玩起来 |
| **上手手册** | 三条路径（终端 curl / Python 交互 / 对话台）逐个带你走，每步真执行真看结果 | 想看清背后 |

**对比功能怎么用（重点）**

图形界面里点「五模型对比」会弹出���个窗口：

- 上面的大输入框里**写你想问什么**（不限于任何预设问题），也可以 ⌘V 粘贴，或点「📋 粘贴剪贴板里的问题」；
- 灰字只是提示，不是真问题：一开始打字或粘贴它就消失；**只有留空时**才对比最近问过的问题；
- 下面**勾选要对比哪几个模型**（全选就是全部，也可以只勾 2 个）；
- 拖滑块可以单独给这次对比设温度；
- 点「开始对比」，每个模型的回答依次显示出来。

**你粘贴什么就对比什么**——不会再跑出预设的货币问题。

终端版对应命令：

```
/对比 你的问题                     # 对比全部 5 个模型
/对比 你的问题 qwen2.5:3b-instruct qwen3-8b-v4flash:flash   # 只对比指定的
/对比                               # 不带参数 = 用你最近问过的问题
```

**最推荐的验证方式**——用 `/对比` 问一个有深度的问题：

```
你> /对比 用一句话解释什么是通货膨胀
```

你会看到 5 个模型分别回答。9B/8B 的准确详尽，**0.5B 的会自相矛盾**（"购买力下降"又说"购买力增加"）。
这就是"模型越大越强"最直观的证据——不用信任何人的说法，自己看一眼。

完整的三条路径说明见 `《上手实验手册》.md`，或直接看电子书里的对应章节。

**每课都可以重复上**。学明白为止，不用赶进度。

## 第 0 课：自由提问（先玩这个）

这是唯一一个**你要自己动手**的课。它会让你：

1. 在终端里输入任何问题，模型当场回答
2. 同一个问题用不同"温度"问两次，亲眼对比差别
3. 让模型起 4 个奶茶店名字，看它每次都不一样

```
  你的问题> 为什么天空是蓝色的？
  ────────────────────────────────────────────────────────
  AI: 天空呈现蓝色主要是由于大气散射现象，特别是瑞利散射……
```

**在这之后**，课程里出现的"我输入：xxx"都是脚本写死的固定问题——不需要你打字。想自己提问随时回第 0 课。

1. **先讲概念**——用大白话讲清楚，不用术语堆砌

## 遇到问题怎么办

### 常见报错对照表

| 屏幕上出现 | 意思 | 怎么办 |
|---|---|---|
| `AI 引擎没有运行` | Ollama 没启动 | 另开一个终端窗口，输入 `ollama serve`，回车，**别关掉这个窗口** |
| `ModuleNotFoundError` | 依赖没装全 | 运行 `bash AI起步/安装环境.sh` |
| `Connection refused` | 同上，引擎没起 | 见第一行 |
| `model not found` | 模型没下载 | 运行 `ollama pull qwen2.5:3b-instruct` |
| `Killed` / 进程突然消失 | 内存不够 | 关掉一些程序再试；或换小模型 `qwen2.5:0.5b` |
| `loss` 变成 `nan` | 学习率太大 | 改成 `1e-4` 或更小 |
| 中文全是乱码 | 用了英文模型 | 本教程已避开；若出现说明走错了课 |
| 双击 .app 没反应 | macOS 安全拦截 | 右键点它 → 选「打开」→ 再点「打开」 |
| 窗口显示"找不到引擎" | Ollama 没开 | 见窗口里的提示，或直接在 WorkBuddy 里问我 |

### 卡住了怎么办

- **第 1 课**卡住 → 检查终端里有没有报错，把报错文字记下来
- **第 5 课**卡住 → 训练本身只需十几秒，如果卡住多半是模型在下载（第一次会慢）
- **任何课**卡住 → 直接跳过，回头再来。**别在一课上耗超过一小时**

## 七课速查卡

打印出来贴在显示器旁边。

### 第 1 课：大模型是什么

```
大模型只会做一件事：接着往下写字。
它写的时候，按"每个词的概率"一个一个挑。
温度控制发挥空间：低=稳，高=野。
它的知识来自训练时读过的海量文本。
所以它会一本正经地胡说——涉及事实必须核对来源。
```

### 第 2 课：提问四心法

```
1. 把话说全 —— 去哪儿、几天、什么预算、给谁看。
2. 给它派个岗 —— 用"你是…"开头。
3. 复杂问题让它先想 —— 加"请一步一步思考"。
4. 要什么格式就给个例子 —— 比描述有效十倍。
```

### 第 3 课：提示词 6 零件

```
① 角色  你是谁
② 任务  要做什么
③ 背景  给谁看、什么场景
④ 输入材料  粘贴原文/数据
⑤ 输出要求  格式、长度、语言、语气、不要什么
⑥ 示例  贴一个你想要的输出样本

AI 写错了 → 指出具体问题 + 说清要什么
（不要说"不对，重来"，它会乱猜）
```

### 第 4 课：技术速查

```
token      模型处理文字的最小单位，API 按它计费
           中文 1 字 ≈ 0.5~1 token（本机实测）
           英文 1 词 ≈ 1~1.5 token（更省）
上下文窗口 一次能看的文字总量，超了报错或静默截断
           塞太多资料反而效果变差，给 3~5 段最相关的
logits     模型给每个候选词打的原始分（可为负）
softmax    把分数变成概率的一步
温度       写代码 0.2 / 日常聊天 0.7 / 创意 1.0 / 别超 1.5
```

### 第 5 课：微调流程

```
准备数据（问答对）→ 格式化成聊天模板 → 加载模型
→ 装 LoRA 补丁 → 设置参数 → 训练 → 保存 → 验证

LoRA：只训 0.1% 参数（加在 q_proj/v_proj 旁的低秩矩阵）
数据量决定上限：20~50 条=演示，几百条=风格，几千条=专业能力
loss 下降=有效，loss=nan=学习率太大
```

### 第 6 课：出错了用哪招

```
① 换更强的模型 / 加上下文    （最便宜，先试）
② RAG 检索增强              （知识要准确时）
③ 微调                      （改风格/口径/能力）
④ 知识编辑                  （只改一条具体事实，秒级）
⑤ 重训                      （换架构，最后考虑）

知识编辑看两个指标：可靠性（改对了吗）+ 局部性（伤到别人了吗）
```

### 第 7 课：水印

```
原理：词表分绿/红名单，生成时按隐藏规则偏置，检测时看 z-score
z-score > 4 基本可判定有水印
强度 0.25~0.5 是甜点区（太弱检不出，太强文本生硬）
弱点：怕改写和翻译，短文本检不准
```

## 学完之后

你已经能：

- 看懂 AI 在做什么、知道它的能力边界在哪
- 自己动手训模型、改模型、检测 AI 文本
- 判断一个 AI 项目该用什么技术、什么硬件
- 不再被术语唬住

**想继续深入**，往这三个方向走：

1. **RAG（检索增强）**——目前企业落地最主流。原理是：资料存进向量库，提问时先检索出相关的，再连同问题一起给模型。学到这个，你的 AI 就能真正处理自己的资料了。

2. **《动手学大模型》原书**——11 章完整实验，包括多模态、强化学习、GUI 智能体。在 `M4学习包/` 目录，有电子书版本。

3. **动手做个小项目**——把你手头一件真实的事交给 AI：
   - 整理一批文档 → 学 RAG
   - 让 AI 按你的口径回答 → 学微调
   - 批量生成文案 → 学提示词 + API 调用
