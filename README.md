# llm-learning-m4

在 Apple M4 / 16GB 内存的 Mac 上，从零学会使用、提问和微调本机大模型。

这里是一套**亲手跑通过**的学习材料：命令能执行，结果能复现，附带实测数据。内容按“教婴儿学步”的方式编排，先讲基础概念，再逐行解释代码，最后给出可以亲手验证的实验。

## 目录

| 目录 | 里面是什么 | 从哪开始 |
|---|---|---|
| `AI起步/` | 零基础八课、图形对话台、终端对话台、上手实验手册、电子书 | 运行 `bash AI起步/启动对话台.sh` |
| `M4学习包/` | M4 定制学习路线、3B/7B 实测脚本、LoRA 训练脚本 | 打开 `M4学习包/M4学习路线.html` |
| `书稿/` | 《动手学大模型》精读本（11 章整理为 5 编） | 打开 `书稿/动手学大模型-精读本.html` |
| `llm-lab-test/` | 实验用脚本 | 按需查看 |

## 三步跑起来

1. **装好 Ollama**（本机 AI 引擎），并保持它在运行。
2. **运行 `bash AI起步/启动对话台.sh`**（macOS 上也可以把该脚本做成自己的 .app 快捷方式）。这会打开一个图形窗口，不用在输入框里敲命令才能提问。
3. 在输入框里提问；输入 `/帮助` 可以看到本机命令清单。

想从零学概念，打开 `AI起步/《AI起步》零基础教程.html`，按第 0 课到第 7 课顺序做。

## 本机实测结论（M4 / 16GB）

| 模型规模 | 可行路径 | 实测 |
|---|---|---|
| 0.5B / 1.5B | PyTorch MPS | LoRA 微调分别占 1.88GB / 5.80GB |
| 3B | PyTorch MPS + **bf16** | LoRA 占 5.78GB，约 1.1~1.8 秒/步；fp32 会 OOM |
| 7B | **MLX 4bit** | 加载 4.0GB，约 11 tok/s；LoRA 微调 60 步约 36 秒 |
| 7B | PyTorch MPS + fp16 | 权重约 15.2GB，超过 MPS 11.84GB 上限，跑不动 |

7B 训练入口：`bash M4学习包/train_7b_lora.sh`。学习率超过 `2e-5` 会训出 nan，实测 `1e-5` + 60 步最稳。

## 图形对话台的本地命令

以 `/` 开头的内容在本机执行，不会发给模型。

| 命令 | 作用 |
|---|---|
| `/帮助` | 显示全部命令 |
| `/模型 <名字>` | 换模型，不带名字则列出可用模型 |
| `/温度 <0~2>` | 调“发挥空间” |
| `/长度 <数字>` | 限制回答长度 |
| `/对比 <问题> [模型名...]` | 让几个模型回答同一个问题 |
| `/历史` / `/清空` / `/退出` | 看记录 / 清空 / 关窗口 |

复制来的文字可以直接 `⌘V` 粘贴，或点「解释剪贴板内容」让 AI 用大白话讲清楚。
